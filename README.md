# Wave Picking System

Sistema de simulación de preparación de pedidos en un warehouse.

## Estructura

- `src/core/`: modelos de dominio
- `src/algorithms/`: pathfinding, wave manager
- `src/simulation/`: motor de simulación
- `src/io/`: carga/exportación de escenarios
- `src/ui/`: visualización
- `tests/`: tests unitarios
- `docs/`: documentación técnica
